发表于 2025-07-04 分类于 Python 阅读次数：

前言

pytest

快速使用

结果解析

结果解析：

  1. 执行环境：版本、根目录、用例数量
  2. 执行过程：文件名称、用例结构、执行进度
  3. 失败详情：用例内容、断言提示
  4. 整体摘要：结果情况、结果数量、花费时间

用例规则

用例发现规则

测试框架在识别和加载用例的过程。

  1. 遍历所有的目录，例外：venv 和.开头的目录
  2. 打开Python文件，test_开头和 _test结尾的文件
  3. 遍历所有的Test开头类
  4. 收集所有的test_开头的函数或者方法

用例内容规则

对用例的要求：

  1. 可调用的（函数、方法、类、对象）
  2. 名字test_开头
  3. 没有参数（参数有另外含义）
  4. 没有返回值（默认为None）

配置

  • -s 允许输入和输出

  • -v/-vv 详细信息

  • -x 快速退出

  • -m 用例筛选

标记

让用例与众不同，可以让用例被区别对待。

步骤：

  1. 先注册
  2. 再标记
  3. 后筛选

2.框架内置标记

可以为用例增加特殊执行效果。

和用户自定义的区别：

  1. 不需要注册，可以直接使用
  2. 不仅可以筛选，还可以增加特殊效果
  3. 不同的标记，增加不同的特殊效果
    1. skip： 无条件跳过
    2. skipif: 有条件的跳过
    3. xfail: 预期失败
    4. parametrize: 参数化
    5. usefixture: 使用fixture

常用插件

pytest-html

pip install pytest-html

使用

pytest --html=report.html

或者在配置文件里加上后，直接使用pytest就行。

pytest-xdist

分布式，加-n 执行

只有任务本身耗时较长，超出调用成本很多的时候，才有意义。

有并发问题：存在资源竞争、乱序

pytest-rerunfailures

重试。适用于网络环境不好，需要渲染的情况。

使用：

pytest-result-log

将执行结果记录到日志文件中。
