简介

生命周期

  1. 客户端发送 HTTP 请求到 Flask 应用。
  2. Flask 通过 url_map（路由映射表）匹配请求 URL 对应的视图函数。
  3. 执行视图函数前，触发 请求前钩子（如 @app.before_request）。
  4. 执行视图函数，生成响应。
  5. 响应经过 请求后钩子（如 @app.after_request）处理。
  6. 响应返回客户端。

Session 的工作流程

  1. 创建 Session：
    用户首次访问时，服务器生成唯一的Session ID（如 UUID），并创建对应的 Session 对象（存储用户数据）。

  2. 传递 Session ID：

    服务器通过 Cookie 将Session ID发送到客户端（通常是JSESSIONID或PHPSESSID）。

  3. 验证 Session：

    后续请求中，服务器通过Session ID查找对应的 Session 对象，获取用户数据。
